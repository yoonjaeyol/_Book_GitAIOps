# 2.6 Notiflex 앱 생성·빌드·배포 (kind 환경)

## 사전 조건

- kind 클러스터(`notiflex`)가 생성되어 있고 노드가 Ready 상태여야 함
- Docker가 설치되어 있어야 함
- Go가 설치되어 있어야 함 (원격 노드에서 빌드 시)

## 실행 지침

### 단계 1: Notiflex API 서버 생성

`app/main.go`를 생성합니다:
- Go 표준 라이브러리만 사용 (net/http)
- 엔드포인트: `GET /health` (상태 확인), `GET /id` (고유 ID 생성)
- `/id`는 인메모리 카운터로 순차 ID 생성, 생성한 Pod 이름을 함께 반환
- 포트: 8080

`app/Dockerfile`을 생성합니다:
- 멀티스테이지 빌드: `golang:1.25-alpine` → scratch
- CGO_ENABLED=0 으로 정적 바이너리

`app/go.mod`을 생성합니다:
- `go mod init notiflex` 실행
- Go 버전은 `1.25`로 설정

### 단계 2: Docker 로컬 빌드 (kind)

kind 환경은 GCP Artifact Registry를 사용하지 않습니다. Docker로 로컬 빌드합니다:

```bash
# 원격 노드에서 빌드
ssh yjy-ubuntu20-test-3 "cd /path/to/app && docker build -t notiflex-api:v0.1.0 ."
```

### 단계 3: kind에 이미지 로드

```bash
ssh yjy-ubuntu20-test-3 "kind load docker-image --name notiflex notiflex-api:v0.1.0"
```

> ⚠️ **ImagePullBackOff**: kind는 외부 registry에 접근하지 못합니다. `kind load docker-image`로 이미지를 반드시 로드해야 합니다.

### 단계 4: K8s 매니페스트 생성 및 배포

`k8s/smb/` 디렉터리에 생성:
- `namespace.yaml`: notiflex 네임스페이스
- `deployment.yaml`: replicas 2, 이미지 `notiflex-api:v0.1.0` (tag만, registry 경로 없음), readiness/liveness probe 포함
- `service.yaml`: ClusterIP, port 80 → targetPort 8080

```bash
# 네임스페이스를 먼저 생성한 후 나머지 리소스를 적용
ssh yjy-ubuntu20-test-3 "kubectl --context kind-notiflex apply -f k8s/smb/namespace.yaml && kubectl --context kind-notiflex apply -f k8s/smb/"
```

> ⚠️ **Namespace race condition**: 한번에 적용하면 namespace not found 에러가 발생할 수 있습니다.

### 단계 5: 배포 확인

```bash
ssh yjy-ubuntu20-test-3 "kubectl --context kind-notiflex get pods -n notiflex"
ssh yjy-ubuntu20-test-3 "kubectl --context kind-notiflex port-forward svc/notiflex-api -n notiflex 8080:80 &"
ssh yjy-ubuntu20-test-3 "curl http://localhost:8080/health && curl http://localhost:8080/id"
```

> ⚠️ **port-forward 접근**: port-forward는 노드 로컬에서만 접근 가능합니다. 외부에서 접근하려면 NodePort 또는 Ingress 설정이 필요합니다.

## 트러블슈팅

### ImagePullBackOff
이미지가 kind에 로드되지 않았습니다. `kind load docker-image`를 다시 실행합니다.

### CrashLoopBackOff
Pod 로그 확인:
```bash
kubectl --context kind-notiflex logs -n notiflex -l app=notiflex-api
```

### Go 미설치
원격 노드에 Go가 없으면 로컬에서 빌드하고 바이너리를 scp로 전송하거나, Docker multi-stage 빌드를 사용합니다.
