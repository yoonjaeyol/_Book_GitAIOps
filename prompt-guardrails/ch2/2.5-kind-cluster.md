# 2.5 kind 클러스터 생성 (GKE 대신 로컬 K8s)

## 사전 조건

- Docker가 설치되어 있어야 함
- kind가 설치되어 있어야 함 (`/usr/local/bin/kind`)

## 실행 지침

### 단계 1: kind 클러스터 생성

```bash
kind create cluster --name notiflex --wait 120s
```

- **클러스터 이름**: `notiflex`
- **Kubernetes 버전**: kindest/node:v1.29.1 (기본)
- **노드**: control-plane 1개 (worker는 필요시 추가)

### 단계 2: kubeconfig 컨텍스트 확인

kind는 생성 후 자동으로 `kind-notiflex` 컨텍스트를 kubeconfig에 추가합니다.

```bash
kubectl config get-contexts | grep kind-notiflex
```

CLAUDE.md의 kubectl 안전 규칙(`--context gke-...`)과 달리, kind는 컨텍스트 이름이 `kind-notiflex`입니다.

```bash
# ✅ 올바른 사용
kubectl --context kind-notiflex get nodes

# ❌ 금지 — 다른 클러스터가 있을 수 있음
kubectl get nodes
```

> ⚠️ **컨텍스트 이름**: 이 환경에서 kubectl 명령은 `--context kind-notiflex`를 반드시 지정합니다.

### 단계 3: worker 노드 추가 (선택)

다수 Pod 동시 실행이 필요하면 worker 노드를 추가합니다:

```bash
kind create node --node-config- < /dev/stdin --name notiflex <<EOF
role: worker
EOF
```

### 단계 4: 클러스터 상태 확인

```bash
kubectl --context kind-notiflex get nodes
```

모든 노드가 `Ready` 상태인지 확인합니다.

### 단계 5: Docker 로컬 registry 설정 (선택)

kind에서 빌드한 이미지를 클러스터에 푸시하려면:

```bash
# kind cluster가 Docker 네트워크에 접근
docker network connect kind <registry-container-name>

# kind config에서 registry 설정
cat <<EOF | kind create cluster --name notiflex --config=-
kind: Cluster
apiVersion: kind.x-k8s.io/v1alpha4
containerdConfigPatches:
- |-
  [plugins."io.containerd.grpc.v1.cri".registry]
    [plugins."io.containerd.grpc.v1.cri".registry.mirrors]
      [plugins."io.containerd.grpc.v1.cri".registry.mirrors."localhost:5000"]
        endpoint = ["http://<registry-ip>:5000"]
EOF
```

단순한 경우 `kind load docker-image`로 직접 로드 가능:

```bash
kind load docker-image --name notiflex notiflex-api:v0.1.0
```

## 트러블슈팅

### ImagePullBackOff 발생
kind는 외부 registry에 접근하지 못합니다. `kind load docker-image`로 로컬 이미지를 로드하거나, 내부 registry를 설정해야 합니다.

### 컨텍스트 충돌
```bash
kubectl config delete-context kind-notiflex 2>/dev/null || true
```

### 리소스 부족
4코어/15GB 환경에서는 control-plane 단일 노드로 충분합니다. 추가 worker가 필요하면 `kind create node`로 추가합니다.

### 클러스터 삭제
```bash
kind delete cluster --name notiflex
```
